# MDedit v0.3.13

## Find and replace focus fixes

Typing in Find no longer transfers focus into the document when a match appears. Previously, subsequent characters could replace document text instead of completing the search query. Enter and Shift+Enter now keep focus in Find while navigating matches.

Pressing Enter in Replace with keeps focus in that field, allowing consecutive replacements without accidentally inserting text into the document.

## Validation

All 81 browser tests and seven editor-tools tests passed locally, including new regression coverage for full and lite builds, keyboard navigation, repeated replacement, search options, invalid regular expressions, capture replacement, Replace All, and undo. The full Node suite passed 355 of 356 tests; the Cargo metadata check could not run because Cargo is not installed locally. Both generated frontend builds were regenerated. Browser checks used an existing local Chromium executable because the Playwright-default browser was not installed. Native desktop runtime behavior was not tested locally; the tag-triggered release workflow runs native builds and tests on Windows, Linux, and macOS, plus browser and performance checks, before publishing desktop downloads.
