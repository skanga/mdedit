# MDedit v0.3.8

## Changes

- Inspect Windows filesystem capabilities before preparing save temporaries.
- Preserve the existing Windows ACL-aware replacement and recovery behavior on supported filesystems.
- Report the specific failing save operation, including capability queries, security preparation, temporary writes/flushes, and publication.
- Add native Windows regression coverage and a manually dispatched WSL-provider workflow for configured self-hosted runners.

## Important limitation

This is a safety and diagnostics release, **not a fix for replacing existing WSL files**. Existing-file replacement on filesystems without Windows ACL support remains rejected when native permissions cannot be preserved. No direct-overwrite or delete-then-rename fallback has been introduced.

To preserve unsaved edits, use **Save As** with a new filename where supported, save a copy to a local Windows folder, or use a filesystem-native editor.

The regular release pipeline tests Windows, Linux, and macOS. The separate WSL-provider workflow requires a configured WSL-capable runner; WSL integration has not been validated as part of this release preparation.
