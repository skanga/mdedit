# MDedit v0.3.11

## Fixes

- Keep the right-hand preview at its current scroll position when editing Markdown in the left pane.
- Keep the current preview visible while the updated render is pending, instead of briefly clearing it.
- Continue clearing the preview when switching documents and clamp scrolling naturally when content becomes shorter.

## Validation

The new browser regression test failed before the fix and passed afterward. Local validation passed all 71 browser tests and 353 unit tests; full and lite web builds were regenerated. Native desktop runtime smoke tests were not performed locally. The tag-triggered release pipeline runs desktop builds/native tests on Windows, Linux, and macOS plus browser and performance gates before publishing packages.
