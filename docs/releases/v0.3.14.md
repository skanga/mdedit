# MDedit v0.3.14

## Editing fixes

- Indent and outdent no longer modify the next line when a selection ends at that line's start.
- Replace advances past the inserted replacement instead of immediately replacing its own output. For example, replacing `cat` with `catfish` twice in `cat cat` now produces `catfish catfish`.

## Export fixes

- PNG and PDF exports include local images without trying to read ordinary hyperlinks as embedded assets. Missing linked documents or attachments no longer block these exports.
- HTML exports continue to embed local images and attachments while preserving Markdown navigation links rather than trying to embed their targets.
- Canceling an HTML, PNG, Markdown, CSV, or SVG export now reports cancellation instead of success. Canceled saves do not advance the saved-content baseline.

## Validation

All 93 browser tests and 355 Node tests passed locally. New regression coverage verifies selection boundaries, literal and regex replacement advancement, export asset filtering, HTML attachment embedding, and export cancellation. Both generated frontend builds were regenerated. Browser checks used an existing local Chromium executable because the Playwright-default browser was not installed. The Cargo-dependent metadata check was excluded because Cargo is not installed locally, and native desktop runtime behavior was not tested locally. The tag-triggered release workflow runs native builds and tests on Windows, Linux, and macOS, plus browser and performance checks, before publishing desktop downloads.
