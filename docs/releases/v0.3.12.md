# MDedit v0.3.12

## File paths at a glance

Hover over a document tab to see its full path. The window title also shows the active file's full path, followed by ` - MDedit`, and retains the unsaved-change marker. Paths update when switching tabs or using Save As. MDedit preserves the complete path; the operating system controls how much of the title bar is visible.

## Open linked Markdown documents

In the desktop preview, links to readable local Markdown files open in a new editor tab. If the file is already open, its existing tab is selected without replacing unsaved edits. Relative links resolve beside the source document, and absolute native paths are supported, including Windows drive-letter paths. Missing or inaccessible targets remain inactive and are checked again before opening.

Supported extensions are `.md`, `.markdown`, `.mdown`, and `.mkd`. Query strings and fragments are excluded from filesystem resolution. Browser-only sessions cannot resolve files on disk.

## Validation

Local validation passed 356 Node tests, 101 Rust tests, the 76-test browser suite, and 11 focused browser checks after the final Windows-link fix. Full and lite frontend builds were regenerated. The tag-triggered release workflow runs native builds and tests on Windows, Linux, and macOS, plus browser and performance checks, before publishing the five desktop downloads. Native Windows/macOS title-bar appearance was not manually inspected locally.
